# JSON для библиотеки виджета

Эта папка в ветке `main` — каталог размеченных кейсов, который читает виджет через GitHub API. Добавляйте один самостоятельный JSON на кейс прямо в эту папку. Передеплой сайта для новых файлов не нужен.

- Имя: `<id>.json`, например `003.json` или `003-N2.json`. ID: латинские буквы, цифры, дефис и подчёркивание, до 100 символов; первый символ — буква или цифра.
- Формат: `schema_version: "case-step-viewer/1.0"`, `title`, `initial_state`, `steps[]` с полными снимками `state_after`.
- [Описание структуры и пример](../README.md), [подробные правила разметки](../HANDOFF.md), [JSON Schema](../schema.json).
- Сохраняйте исходные сообщения и ссылки на подтверждения. Не добавляйте будущие факты в ранние состояния и не закрывайте ожидание исполнителя без его ответа.
- Новая ветка сценария — отдельный файл. Существующие чужие файлы не перезаписывайте.
- Файлы в этой папке отображаются в открытой библиотеке сайта. Секреты и закрытые реальные данные сюда не добавляйте.

Проверка из корня репозитория (Node.js):

```sh
node --input-type=module -e 'import fs from "node:fs"; import {validateCase} from "./case-state-widget/viewer.js"; for (const name of fs.readdirSync("case-state-widget/cases").filter(x=>x.endsWith(".json"))) { validateCase(JSON.parse(fs.readFileSync("case-state-widget/cases/"+name,"utf8"))); console.log("OK",name); }'
```

Каталог обновляется при открытии страницы, кнопкой «Обновить список» и периодически, пока вкладка открыта. Для новых кейсов обновлять `index.html`, `app.js` или отдельный manifest не нужно.
