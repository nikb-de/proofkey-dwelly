## Finite intake and strict local schemas

InterfaceLimitsV1 defaults: input1048576bytes, positions256, depth32, publisher ledger/readback4194304bytes; exact positive finite integers, no body override. Input byte bound also bounds node count. Publisher cap applies cumulatively to its own canonical ledger bytes and each bounded export readback, not all exporter/pending bytes or physical latency.

Inputs are exact UTF-8 JSON-list bytes or exact finite list/tuple; top-level rows may additionally be exact CanonicalRequest. Other children are exact JSON scalar/list/dict values only; no nested model/tuple, custom Mapping/serializer/repr/generator. Detach before callbacks. Reject duplicate JSON keys, nonfinite values, invalid UTF-8/surrogates, cycles/depth/nodes/size/N or non-list root as invalid_document with N=None, zero entries and no invented positions. No root is allocated for whole-document/standalone command parse failure; return a safe in-memory receipt with publication not_started. Preserve actually computed bounded invalid byte hash only, never oversized/unrepresentable or guessed fragment hash. Empty valid list has N=0.

Use additive strict frozen host-local models with unknown fields forbidden, finite numbers, aware timestamps, exact IDs/hashes and validator-enforced cross-field joins. Detach/revalidate complete existing wire/hash/coherence at every consumed publication boundary and retain no caller-owned mutable input/config object. These snapshots are not a defense against arbitrary hostile local Python or a permission/custody claim. Existing host/shared schemas and their meaning stay unchanged.
