# Coordination review and customer preview

## Why

The durable delivery-terms backend had no complete Team/Customer workflow controls. Connect the existing workflow to those interfaces while keeping a model proposal advisory context for an explicit operator command, never executable authority. Preserve the existing local sandbox boundary and generic model output schema.

## What Changes
- Current, succeeded, source-bound model run references on reviewed coordination commands.
- Team controls for every existing coordination command, complete terms, evidence, freshness and receipts.
- Atomic local-preview acceptance of an exact offer; no authenticated customer or external booking claim.
- Regression and browser verification without paid provider calls.

## Non-goals
Real carrier communication, identity authentication, autonomous financial actions, a new model provider schema, cloud deployment or changed historical jobs.
