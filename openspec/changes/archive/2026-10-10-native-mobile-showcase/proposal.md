# Native mobile showcase

## Why
The previous presentation reads as a website scaled down, not a mobile product. The user requests a rounded mobile interface and a 40-second film.

## What changes
- Replace the showcase layout with a clipped rounded phone, status area, native-style app header, cards, bottom navigation and safe areas.
- Preserve the five source-backed scenes and separate scripted/recorded-model modes.
- Use five eight-second scenes and export exactly 40 seconds, 1080×1920 at 30 fps.
- Keep playback controls outside the captured phone and retain an in-app replay label.

## Impact
Only the presentation UI, capture/export tools and showcase documentation change. No backend state, model execution, source data or integration authority changes.
