# Design

Use a normal two-parent merge from main, explicitly allowing the known unrelated roots. Resolve common files semantically. Keep the GitHub library's routes on its own server; its case envelope is not the model-analysis API. Register current team cases in a separate pinned manifest with namespaced IDs. Legacy fixture identity and cutoffs remain unchanged. Source-authored limits are context, never authenticated policy or permission grants. Copied participants remain visible in evidence.

Independent ownership: widget files; Python analysis/bridge and team manifest; root documentation/prototype/model conflicts and verification. Shared public contract stays case-step-viewer/1.0.
