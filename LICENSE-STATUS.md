# Licence and distribution status

`LICENSE` supplies Apache-2.0 for eligible original application code contributed to this project. `NOTICE.md` defines the exclusions. It does not establish ownership, contributor grants, dataset permission or compliance by itself.

The user-authorized [data package](data/dwelly-public-cases/README.md) is a private/internal copy of public Dwelly development cases, public attachments, normalized JSON and pilot outputs. No dataset licence was identified in the inspected upstream snapshot. These materials and their derived excerpts are **not re-licensed under Apache-2.0**. Public accessibility and private storage are not redistribution permission.

Two intake tests retain exact excerpts from public Dwelly examples: case 001 in `tools/dwelly_cases/tests/test_pilot.py` and case 023 in `tools/dwelly_cases/tests/test_validation.py`. Their inclusion is not a public-ready rights clearance. Before a public release, establish permission or replace those excerpts with independently authored fixtures and rerun tests.

Before public distribution, record the exact paths/hashes, origin, owner or contributor grant, applicable terms and required notices for every included code, test, data and media file. Provider services/output and the Docker base image have separate terms. The private operational runtime and its dependencies are not included in this release.

No private conversations, private Drive originals, private recordings, runtime artifacts, credentials or parent repository history are included. A clean secret scan reduces accidental disclosure risk; it does not prove ownership, legal clearance or absence of all sensitive data.
