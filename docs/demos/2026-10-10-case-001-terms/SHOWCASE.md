## Boundaries

- The scenario itself is synthetic author-labelled development data, with dates rebased from February to October.
- The LLM variant reuses five actual `gpt-6.1-sol` responses from the prior successful capture. No new paid call occurs during playback.
- Historical model advice is not current execution authority. The first model's suggestion differs from the recorded operator's cancellation step; no model consensus or accuracy score is claimed.
- Acceptance advances the recording; it sends no request. Dispatch readbacks and booking receipts are local sandbox records. Physical delivery is not confirmed.
- All hashes, source IDs and model identities remain available in the default audit viewer and manifests. The clean presentation does not expose them on screen.

## Files and reproduction

UI: `platform-ui/showcase.html`, `showcase.css`, `showcase.js`.

Data: `platform-ui/showcase-data-llm.json` and `showcase-data-synthetic.json`, generated by `tools.dwelly_platform.showcase` from the immutable capture reports linked in `RECORDINGS.md`. The builder validates case identity, historical cutoff, model input binding and final sandbox receipt. It refuses to overwrite a source or existing output.

```sh
node docs/demos/2026-10-10-case-001-terms/record-showcase.mjs <new-output-directory>
node docs/demos/2026-10-10-case-001-terms/export-showcase.mjs <new-output-directory>
```

Set `PROOFKEY_PRESENTATION=1` on the recorder command to capture the clean presentation variant. This uses a separate view flag; it does not disable evidence validation or change runtime behavior.

The recorder checks all five mobile scenes, exports desktop views, observes browser errors and unexpected writes, then records both modes in parallel. The logical 450×800 composition is rendered at 2× inside a 900×1600 browser viewport and exported at 1080×1920. `capture.json` contains raw-video paths, logical/physical geometry, source hashes and scene timestamps. Its absolute filesystem paths describe the original capture machine; they are historical provenance, not portable paths. Raw WebMs remain local, while the final MP4s, reference screenshots and decoded QA frames are published. See [PUBLICATION.md](PUBLICATION.md) for current relative paths. This browser recording is not generative video.
